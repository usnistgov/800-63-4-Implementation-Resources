Comments
=========

We welcome comments on these implementation resources and on the SP 800-63-4
Digital Identity Guidelines. You can reach us by email or on GitHub.

Send an email to dig-comments@nist.gov with the following information:

- Name: (optional)
- Contact Email: (optional)
- Organization: (optional)
- Volume or Resource Reference:
- Topic: Brief description of the topic to which the comment is related
- Comment:

You can also `open an issue
<https://github.com/usnistgov/800-63-4-Implementation-Resources/issues>`__ on the
project repository. GitHub issues are public, so please do not include anything
you would not want posted publicly.
